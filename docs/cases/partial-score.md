# 缺失结果不再获得完整总分

来源：`apps/eval/src/score.test.ts` 的固定评分夹具。

一个 skill 有三条触发用例和一条清晰度作业，只收到清晰度结果（80 分），静态分为 100。

原行为：缺少触发层时，把剩余层权重重新分配，总分为 90。这个数字不能证明完整评测有效。

修复后：完成率为 25%，错误数为 3，总分为空，状态为“评测未完成”。HTTP 错误、非布尔触发结果、缺失作业和重复作业也不能获得完整总分。

新作业绑定 skill 与用例指纹，执行期间版本变化标记为 stale；旧成绩明确标为未绑定版本。

验证命令：

```bash
npx vitest run apps/eval/src/score.test.ts
```
