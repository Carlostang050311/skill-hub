# 模型满分，产物却不存在

来源：`apps/eval/src/artifacts.test.ts` 的执行与评审夹具。

执行者声称生成 `report.md`，评审返回通过，还重复输出同一评分项；实际目录没有该文件。

原行为：依赖自述和文件列表，重复的 pass 项可能抬高评分。

修复后：独立读取产物；检查存在、非空、JSON、指定内容和固定 Node 检查。核查单按预定项计分，重复项只算一次，冲突判定从严；程序检查失败不能获得整体通过。

评审可看到真实文本截取和二进制大小/指纹。截取明确标识，绝对路径、越界路径和符号链接被拒绝。工作目录约束不等于操作系统隔离。

验证命令：

```bash
npx vitest run apps/eval/src/artifacts.test.ts
```
