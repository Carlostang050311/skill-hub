# 可复现的失败案例

这里记录来自真实代码回归夹具的故障与修复，均可运行指定命令复现。它们不是外部用户案例或真实模型质量成绩。

| 案例 | 原因 | 验收 |
| --- | --- | --- |
| [资源漂移](resource-drift.md) | 正文相同掩盖脚本、二进制与文件路径变化 | 目录指纹、预览、备份和完整恢复 |
| [不完整成绩](partial-score.md) | 缺失结果重新分配权重，可能制造高分 | 全部作业有效才生成完整总分 |
| [产物证据](artifact-evidence.md) | 模型声称产物存在，或重复评审项放大分数 | 读取真实文件、固定核查单、程序检查 |

本轮还覆盖跨卷备份失败回滚、损坏任务恢复、评测副本绑定与可比版本限制。详细证据见 [验收记录](../implementation-acceptance.md)。
